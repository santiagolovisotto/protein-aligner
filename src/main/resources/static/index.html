Bioinformática · Alineamiento de secuencias

Comparación de proteínas

Alineamiento global (Needleman-Wunsch) y local (Smith-Waterman) entre dos entidades de cualquier entrada del Protein Data Bank.

¿Qué hace esta herramienta?

Una proteína es una cadena de aminoácidos, y cada aminoácido se escribe con una letra. Cuando dos proteínas descienden de un antepasado común, sus secuencias de letras se parecen. Esta herramienta pone las dos secuencias una al lado de la otra, letra por letra, y mide cuánto se parecen.

Cómo usarla: 1) escribí el código PDB de cada proteína (el identificador de una estructura en el Protein Data Bank, por ejemplo 4HHB) o tocá un ejemplo; 2) elegí el tipo de comparación; 3) apretá Comparar.

¿Cómo leer estos números?
Alineamiento
Es la forma de acomodar las dos secuencias, una sobre otra, para que las letras equivalentes queden en la misma columna. A veces hay que dejar un hueco en una de las dos para que el resto encaje.
Identidad
Porcentaje de columnas donde las dos proteínas tienen exactamente el mismo aminoácido.
Similitud
Identidad más las columnas con aminoácidos distintos pero de propiedades químicas parecidas, que se reemplazan con frecuencia entre proteínas emparentadas (la matriz BLOSUM62 les da puntaje positivo).
Hueco (gap)
Una columna donde una de las proteínas no tiene aminoácido. Representa una inserción o una pérdida de aminoácidos a lo largo de la evolución.
Score
Puntaje total: suma lo que la matriz le asigna a cada par de letras alineadas y resta una penalización por cada hueco. No es un porcentaje y crece con el largo de las proteínas, así que sirve para comparar alineamientos hechos con los mismos parámetros, no para comparar pares de proteínas de distinto tamaño.
